Cloud Concepts Reflection
Cloud computing has become a part of my daily life because many of the applications I use rely on cloud technology. Three cloud services I regularly use are Google Drive, Canva, and Facebook Messenger.

Google Drive is an example of Software as a Service (SaaS) because it allows users to store, access, and share files through a web browser without installing or managing the underlying infrastructure. It uses the Public Cloud deployment model since the service is available to anyone with a Google account over the internet.

Canva is also classified as SaaS because it provides online graphic design tools that users can access through a browser or mobile app. Like Google Drive, Canva operates on the Public Cloud because it is hosted by the provider and available to the general public through the internet.

Facebook Messenger is another SaaS application because it offers instant messaging, voice calls, and video calls without requiring users to manage servers or software updates. It also uses the Public Cloud deployment model since Meta provides the service to millions of users worldwide through cloud infrastructure.

Version control is essential when working with cloud infrastructure because it keeps a complete history of changes made to files, scripts, and configurations. If a mistake occurs, developers can easily review previous versions and restore a working configuration. This reduces the risk of errors and makes cloud projects more reliable.

Git and GitHub make collaboration much easier by allowing multiple team members to work on the same project without overwriting each other's changes. Features such as branches, pull requests, and commit history help teams review updates before they are merged into the main project. GitHub also provides a centralized repository where everyone can access the latest version of the project, making it easier to manage cloud resources, track progress, and maintain consistency throughout development. Overall, using Git and GitHub improves teamwork, organization, and the reliability of cloud infrastructure projects.
